<br><h4 align="center">FOR PARAMETERS</h2>

###### • Selected Month Parameter

```ruby
Data Type: Date
Display Format: MMM YYYY (Custom)
Allowable values: List
List values: When Workbook Opens from "Month (For Parameter)" fields
```

<h4 align="center">FOR CM AND PM FIELDS</h2>

###### • Revenue CM
      
```ruby
IF DATETRUNC('month', [Order Date]) = [Selected Month Parameter]
THEN [Payment]
END
```

###### • Revenue PM
      
```ruby
IF DATEADD("month", -1, DATETRUNC("month", [Selected Month Parameter])) = DATETRUNC("month",[Order Date])
THEN [Payment]
END
```

###### • Revenue Change (%)
      
```ruby
(SUM([Revenue CM]) - SUM([Revenue PM]) ) / SUM([Revenue PM])
```

###### • Revenue - (C) Change (%)
      
```ruby
IF [Revenue Change (%)] = 0 THEN 'GRAY'
ELSEIF [Revenue Change (%)] > 0 THEN 'GREEN'
ELSEIF [Revenue Change (%)] < 0 THEN 'RED'
ELSE 'BLACK'
END
```

###### • Returned Quantity CM
      
```ruby
IF DATETRUNC('month', [Order Date]) = [Selected Month Parameter]
THEN [Returned Quantity]
END
```

###### • Quantity CM
      
```ruby
IF DATETRUNC('month', [Order Date]) = [Selected Month Parameter]
THEN [Quantity]
END
```

###### • Quantity PM
      
```ruby
IF DATEADD("month", -1, DATETRUNC("month", [Selected Month Parameter])) = DATETRUNC("month",[Order Date])
THEN [Quantity]
END
```

###### • Orders CM
      
```ruby
COUNTD(
IF DATETRUNC('month', [Order Date]) = [Selected Month Parameter]
THEN [Order ID]
END)
```

###### • Orders PM
      
```ruby
COUNTD(
IF DATEADD("month", -1, DATETRUNC("month", [Selected Month Parameter])) = DATETRUNC("month",[Order Date])
THEN [Order ID]
END)
```

###### • Orders CM (Return)
      
```ruby
COUNTD(
IF DATETRUNC('month', [Order Date]) = [Selected Month Parameter] AND [Retur Status] = "Returned"
THEN [Order ID]
END)
```

###### • Orders CM (Cancel)
      
```ruby
COUNTD(
IF DATETRUNC('month', [Order Date]) = [Selected Month Parameter]
THEN [Order ID]
END)
```

###### • Orders Pairs CM
      
```ruby
COUNT(
IF DATETRUNC('month', [Order Date]) = [Selected Month Parameter]
THEN [Order Id - DIM Category Pair]
END)
```

###### • AOV CM
      
```ruby
SUM([Revenue CM])/[Orders CM]
```

###### • Orders DIM CM
      
```ruby
COUNT(
IF DATETRUNC('month', [Order Date]) = [Selected Month Parameter]
THEN [Order ID - DIM]
END)
```

###### • Orders DIM PM
      
```ruby
COUNT(
IF DATEADD("month", -1, DATETRUNC("month", [Selected Month Parameter])) = DATETRUNC("month",[Order Date])
THEN [Order ID - DIM]
END)
```

###### • Orders DIM Change (%)
      
```ruby
([Orders DIM CM] - [Orders DIM PM]) / [Orders DIM PM]
```

###### • Orders DIM - (C) Change (%)
      
```ruby
IF [Orders DIM Change (%)] = 0 THEN 'GRAY'
ELSEIF [Orders DIM Change (%)] > 0 THEN 'GREEN'
ELSEIF [Orders DIM Change (%)] < 0 THEN 'RED'
ELSE 'BLACK'
END
```

<h4 align="center">FOR DISPLAY</h2>

###### • (Display) DIM Orders DIM Change (%)
      
```ruby
IF ISNULL([Orders DIM Change (%)]) THEN
    "No Data"

ELSEIF [Orders DIM Change (%)] = 0 THEN
    "No Changes"

ELSE
    IF ROUND(ABS([Orders DIM Change (%)] * 100), 2)
        = INT(ROUND(ABS([Orders DIM Change (%)] * 100), 2)) THEN

        IF [Orders DIM Change (%)] > 0 THEN
            "▲" + STR(INT(ROUND(ABS([Orders DIM Change (%)] * 100), 2))) + "%"
        ELSE
            "▼" + STR(INT(ROUND(ABS([Orders DIM Change (%)] * 100), 2))) + "%"
        END

    ELSE

        IF [Orders DIM Change (%)] > 0 THEN
            "▲" + STR(ROUND(ABS([Orders DIM Change (%)] * 100), 2)) + "%"
        ELSE
            "▼" + STR(ROUND(ABS([Orders DIM Change (%)] * 100), 2)) + "%"
        END

    END
END
```

```ruby
    IF ROUND(ABS([Revenue Change (%)] * 100), 2)
        = INT(ROUND(ABS([Revenue Change (%)] * 100), 2)) THEN

        IF [Revenue Change (%)] > 0 THEN
            "▲" + STR(INT(ROUND(ABS([Revenue Change (%)] * 100), 2))) + "%"
        ELSE
            "▼" + STR(INT(ROUND(ABS([Revenue Change (%)] * 100), 2))) + "%"
        END

    ELSE

        IF [Revenue Change (%)] > 0 THEN
            "▲" + STR(ROUND(ABS([Revenue Change (%)] * 100), 2)) + "%"
        ELSE
            "▼" + STR(ROUND(ABS([Revenue Change (%)] * 100), 2)) + "%"
        END

    END
END
```

###### • (Display) Revenue CM
      
```ruby
IF ABS(SUM([Revenue CM])) >= 1000000000 
    THEN "Rp" + STR(ROUND(SUM([Revenue CM]) / 1000000000, 1)) + " M"
ELSEIF ABS(SUM([Revenue CM])) >= 1000000
    THEN "Rp" + STR(ROUND(SUM([Revenue CM]) / 1000000, 1)) + " JT"
ELSEIF ABS(SUM([Revenue CM])) >= 1000
    THEN "Rp" + STR(ROUND(SUM([Revenue CM]) / 1000, 1)) + " K"
ELSE "Rp" + STR(ROUND(SUM([Revenue CM])))
END
```


```ruby

```

```ruby
([(KPI) Orders CM] - [(KPI) Orders PM]) / [(KPI) Orders PM]
```


```ruby
TOTAL([Orders PM])
```


###### • (KPI) Quantity CM
      
```ruby
TOTAL(SUM([Quantity CM]))
```

###### • (KPI) Quantity PM
      
```ruby
TOTAL(SUM([Quantity PM]))
```

###### • (KPI) Return Rate (%)
      
```ruby
[(FIXED) Orders CM Retur - Month] / [(FIXED) Orders CM - Month]
```

###### • (KPI) Revenue Change (%)

```ruby
([(KPI) Revenue CM] - [(KPI) Revenue PM]) / [(KPI) Revenue PM]
```

